Overview

Flip Shift Sync is a Microsoft Excel Office Web Add-in that reads shift plan data from a spreadsheet and syncs it into Flip via the Integration Shifts API (v4).

It runs as a task-pane panel inside Excel (Desktop or Office 365 Web) and supports:

  • Reading shift data from any worksheet with the correct column headers
  • Automatic username-to-UUID lookup via the Flip Users API
  • Date range filtering with per-user scoped syncs
  • Auto-generated external IDs written back to the sheet for stable shift identity
  • Shift notifications toggle

Installation

  1. Download manifest.xml from the home page
  2. Open Excel (Desktop or Office 365 Web)
  3. Go to Insert → Add-ins → Upload My Add-in
  4. Browse to the downloaded manifest.xml and click Upload
  5. Click Shift Sync on the Home tab to open the task pane
Updating the add-in The add-in loads its code from GitHub Pages, so code updates take effect automatically when you reopen the task pane. You only need to re-upload manifest.xml if the manifest itself changes (rare).

API Client Permissions Your Flip API client must have the SHIFT_MANAGEMENT role to use the Integration Shifts API. Create one in Flip Admin under Settings → API Clients.

Settings are saved to your browser's localStorage and persist across sessions.

Spreadsheet Format

The first row of your worksheet must contain column headers. Click Generate Template in the add-in to create a pre-formatted worksheet.

Column Required Description Format
employee_id Required* Flip user UUID ad952350-1808-4c38-...
username Optional Flip username for auto-lookup when employee_id is empty jsmith
start_date Required Shift start date 2026-03-01 or Excel date
start_time Required Shift start time 08:00 or Excel time
end_date Required Shift end date 2026-03-01 or Excel date
end_time Required Shift end time 16:00 or Excel time
external_id Optional Unique shift identifier (auto-generated if blank — see below) shift-001 or auto
location Optional Free-text location label Office A

* If employee_id is empty but username is provided, the add-in will automatically look up the Flip user UUID and write it back to the cell.

Excel native dates & times The add-in handles both text values (2026-03-01, 08:00) and Excel's native date serials and time fractions. You can format date/time columns however you like.

External ID & Shift Identity

Every shift sent to Flip must have an external_id — a unique key that identifies the shift across sync sessions. This is how Flip knows whether to update an existing shift or create a new one.

How it works

  1. First sync — If the external_id column is blank (or doesn't exist), the add-in auto-generates a deterministic ID based on the employee, start time, and end time: 
    excel-{employeeUUID}-{startDigits}-{endDigits}
    This generated ID is written back into the Excel sheet so it persists.
  2. Subsequent syncs — The cell now has an external_id. Even if you change the shift times (e.g. 10:00–15:00 → 10:00–14:00), the same ID is sent, so Flip updates the existing shift rather than creating a duplicate.
  3. New shifts — Add a new row with a blank external_id. On the next Read Sheet, a new ID is generated and written back.
  4. Custom IDs — You can provide your own external_id values. If the cell is not empty, the add-in uses your value as-is and does not overwrite it.
Tip If the sheet doesn't have an external_id column at all, one is automatically added at the end when you click Read Sheet.

How Syncing Works

The add-in communicates with the Flip Integration Shifts API (v4) using a three-phase sync protocol:

Sync Lifecycle
1. Start Sync → get sync_id
2. Send Shifts → POST shift data in batches
3. Complete Sync → finalize and replace

What happens on Complete

When a sync session is completed, shifts not included in the sync are deleted within the sync scope. This is the API's "full replacement" model:

  • Shifts you send → created or updated (matched by external_id)
  • Shifts you don't send → deleted from Flip
Important This means if you remove a row from your spreadsheet and re-sync, that shift will be deleted from Flip. This is by design — your spreadsheet is the source of truth.

Authentication

The add-in uses OAuth2 Client Credentials flow to obtain an access token from your Flip tenant. Tokens are automatically refreshed when they expire.

Date Range & Per-User Sync

When you click Read Sheet, a date range picker appears pre-populated with the earliest and latest shift dates in your data. You can adjust this range to control which employees are affected by the sync.

How per-user sync works

  1. The add-in identifies which employees have at least one shift within the selected date range
  2. For each affected employee, it runs a separate user-scoped sync:
    • POST /sync/start with user_id = that employee's UUID
    • Sends all of that employee's shifts from the spreadsheet (not just the ones in the date range)
    • Completes the sync
  3. Employees not in the date range are completely untouched — their existing shifts in Flip remain as they are
Why send all shifts for each employee? Because complete deletes shifts not included in the sync. If we only sent shifts within the date range, all of that employee's other shifts would be deleted. By sending all their shifts, we ensure a complete replacement scoped to just that employee.

Preview stats

The date range picker shows two live stats:

  • Shifts in range — how many shift rows fall within the selected dates
  • Employees — how many unique employees will be synced

Architecture

System Architecture

Excel (Office.js) → Flip Shift Sync Add-in → Cloudflare Worker (CORS Proxy) → Flip API

GitHub Pages hosts the add-in • Cloudflare Worker proxies API calls to bypass CORS

Tech stack

  • React 18 + TypeScript — UI framework
  • Fluent UI v9 — Microsoft design system for Office add-ins
  • Office.js — Excel JavaScript API for reading/writing worksheet data
  • Webpack 5 — module bundler
  • GitHub Pages — static hosting for the add-in
  • Cloudflare Worker — CORS proxy to relay API requests to your Flip tenant

Key source files

FilePurpose
App.tsxMain component — orchestrates read, transform, sync
excelService.tsReads/writes Excel data via Office.js
transformService.tsConverts sheet rows into Flip API shift objects
flipApiService.tsHTTP client for the Flip Integration Shifts API
syncOrchestrator.tsRuns the sync lifecycle (start → send → complete)
dateRangeService.tsDate range filtering and per-user grouping
authService.tsOAuth2 Client Credentials token management
userLookupService.tsUsername → UUID resolution via Flip Users API

Data flow

  1. Read Sheet — excelService reads the active worksheet via Office.js, maps columns, validates rows
  2. Transform — transformService converts rows into FlipShift objects, generates external IDs, writes them back
  3. Username Lookup — userLookupService resolves any missing employee_ids via the Flip Users API
  4. Sync — syncOrchestrator runs either a single org-wide sync or per-user syncs (based on date range)

Troubleshooting

Common issues

ProblemSolution
Task pane shows 404 or blank page Re-download manifest.xml and re-upload it in Excel. The manifest URLs may have changed.
"Authentication failed" error Check your Client ID and Client Secret in Settings. Ensure the API client has the SHIFT_MANAGEMENT role.
"Sync already in progress" error A previous sync session wasn't completed or cancelled. Wait a few minutes for it to time out, or create a new API client.
Duplicate shifts in Flip Make sure your external_id column has values. Click Read Sheet to auto-populate any blank cells. Re-sync to update.
Shifts not being deleted The sync's "complete" step deletes shifts not included. Ensure you're syncing the correct date range and that the affected employee's all remaining shifts are in the sheet.
Employee ID warnings Flip requires user UUIDs (not names). Either paste UUIDs directly into employee_id, or fill in the username column and let the add-in look them up.
CORS errors in console You need a CORS proxy for hosted deployments. Set the CORS Proxy URL in Settings to your Cloudflare Worker URL.
Shifts appear in Flip but don't disappear after removal Flip's mobile app may cache shift data. Pull to refresh or close and reopen the app.
